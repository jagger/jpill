# Security policy

jPill stores health-related data on the device and makes no network connections, so most security issues are about local data exposure (for example data leaking through notifications, backups, exported files or the app lock).

## Reporting a vulnerability

Please report privately through GitHub: **Security tab > Report a vulnerability** on this repository. Do not open a public issue for something exploitable, and do not include real health data in a report.

You can expect an acknowledgement within a few days. jPill is maintained by one person in spare time, so fixes are best effort, but security reports are prioritised over features.

## Supported versions

Only the latest release is supported.
